# OnePixelOkGoGo

> one-pixel-ok-gogo overlay & smart guides — right inside your browser.

[English](README-en.md) · [繁體中文](README-zh-TW.md) · [日本語](README-ja.md) · [Français](README-fr.md)

> **デザインカンプをライブページに重ねて、1px 単位で微調整できる Chrome 拡張機能。**
>
> Figma と Chrome を切り替える必要はもうありません。

![Hero](screenshots/hero.png)

---

## なぜ必要？

よくある光景ですよね — デザイナーが「2px ずれてる」「間隔がおかしい」「フォントが少し動いてる」と言い訳する場面。
この拡張機能は **デザインカンプを直接ライブページに重ねて**、ピクセル単位で微調整できます。

| 悩み | 解決 |
|------|------|
| Figma と Chrome の行き来 | **ページ上に半透明レイヤー** |
| 間隔が 8 の倍数か分からない | **ガイドを 2 本置くと自動計算** |
| 複数の区块を对齐 | **複数レイヤー個別表示/ロック** |
| 操作が面倒 | **方向キーで 1px / 10px 調整** |

## 機能

### 1. レイヤー — デザインカンプの重ね表示

![Layers](screenshots/layers.png)

- 画像ファイル 最大 50 枚をアップロード / ペースト / ドラッグ
- 透明度・拡大縮小・X/Y をリアルタイム調整
- **5 方向スナップ**：上下左右中央にビューーポート全体整列
- **ドラッグ + 方向キー** で微調整（1px / Shift+10px）
- レイヤー毎 **表示 / ロック / 削除**

### 2. ガイド — 間隔測定

![Guides](screenshots/guides.png)

- **横 / 縦** ガイド線をワンプッシュで追加
- ビューーポート上の好きな場所に **ドラッグ** 可能
- 同軸ガイド間の **自動間隔ラベル表示**
- グローバルスタイル：太さ / スタイル（破線・実線・点線・二重線）/ 色
- **表示 / ロック** で誤操作防止

### 3. フローティングパネル

![Panel](screenshots/panel.png)

- ページ注入型の **ドラッグ可能なサイドバー**
- **Layers** と **Guides**  两个のタブ切替
- 邪魔になったら好きな位置に移動可能

## ショートカット

| キー | アクション |
|------|-----------|
| **⌥⌘S / Alt+Ctrl+S**（Guides タブ）| ガイド表示切替 |
| **⌥⌘C / Alt+Ctrl+C**（Guides タブ）| ガイドロック切替 |
| **⌥S / Alt+S** | 現在レイヤーの表示切替 |
| **⌥C / Alt+C** | 現在レイヤーのロック切替 |
| **↑ ↓ ← →** | レイヤー 1px 移動 |
| **Shift + ↑↓←→** | レイヤー 10px 移動 |

## インストール

> Chrome Web Store からインストール可能：

[**OnePixelOkGoGo — Chrome Web Store**](https://chromewebstore.google.com/detail/onepixelokgogo/mgojihpngfjnhidaeoeedjbkcegddcdc)

または解凍して読み込む方法：

1. このリポジトリをダウンロード / クローン
2. Chrome を開く → `chrome://extensions`
3. 右上隅で **開発者モード** を有効化
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリック → プロジェクトフォルダを選択
5. アイコンをツールバーにピン留め

## クイックスタート

1. **OnePixelOkGoGo アイコン** をクリック → フローティングパネルが表示
2. **Layers** タブでデザインカンプをペースト / ドラッグ
3. 透明度を 50% に設定し、↑↓←→ でページに位置合わせ
4. **Guides** タブに切り替え、「+ Horizontal」をクリック、ドラッグして測定位置を指定
5. もう一本追加すると **自動表示された間隔を確認**
